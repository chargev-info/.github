### What ChargEV does
- 🌍 **1,000,000+** charging points across **100+ countries**
- 🔌 **Every plug, every speed** — CCS, CHAdeMO, Type 2, NACS, GB/T
- 🟢 **Live slot status** — know a charger is working and free *before* you go
- 🧭 **One-tap directions** to the charger
- 🏢 **For everyone** — drivers, charging-point owners, operators & housing societies (RWAs)
- 🗣️ **8 languages** — English, 한국어, Deutsch, Français, Bahasa Melayu, Filipino, 中文, العربية
